## Rappels rapides

- **Police** : Sora (texte) + DM Mono (valeurs, labels uppercase)
- **Fond** : `#f0ede8` / Composants : `#e8e4de`
- **Layout** : shell > sidebar (272px) + sb-content > topbar (56px) + main
- **Tooltip** : `title` + CSS `::after` sur tous les boutons icône
- **Archive** : toujours copier dans `_archive/` avant de modifier
- **Fonctionnalités** : 0 perte tolérée lors d'un restyling
